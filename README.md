# spa-orm2 — ORM2 Viewer

Автономное веб-приложение для просмотра и редактирования концептуальных моделей **ORM2** (Object-Role Modeling) с альтернативным отображением в нотации **Barker ER** и вводом бизнес-правил на русском языке.

Работает целиком в браузере: без сервера, сборки и внешних зависимостей. Весь код — HTML, CSS и JavaScript — упакован в один файл.

## Открыть в браузере

## Ключевой функционал

### Работа с моделью ORM2

* **Загрузка** файлов `.orm` / `.xml` в формате ORM2 (схемы Neumont `ORMCore`, `ORMDiagram`, `ORMRoot`) — через выбор файла.
* **Создание** новой пустой модели с нуля.
* **Сохранение** модели обратно в ORM XML с сохранением исходной структуры документа: правки синхронизируются в XML-дерево, а не пересобирают его заново.
* **Режим строгой совместимости с NORMA** (`strictNormaExport`) — очистка служебных артефактов редактора и нормализация reference modes, чтобы результат открывался в NORMA.
* **Валидация экспорта** и отчёт о совместимости, доступный для скачивания.
* Разбор ORM-элементов: `ObjectType`/`ValueType`, `Fact`, `FactRoles`, `ReadingOrders`/`Readings`, `UniquenessConstraint`, `MandatoryConstraint`, `PreferredIdentifier`, `ReferenceModeKinds`, `DataTypes`, `RoleSequence`, `PlayedRoles`.

### Редактирование диаграммы

* **Добавление объектов:** тип-сущность (EntityType) и значение (ValueType).
* **Создание фактов:** унарные, бинарные и тернарные — выбором соответствующего числа объектов на диаграмме.
* **Перетаскивание** фигур мышью, автоматический лейаут для моделей без координат.
* **Свойства объекта:** имя, тип, reference mode, независимость (`independent`), тип данных (Текст, Целое число, Счётчик, Не указан).
* **Свойства факта:** имя и текст чтения (reading).
* **Быстрое редактирование** объекта, факта и роли через контекстное меню.
* **Удаление** объектов, фактов и ограничений.
* **История изменений:** Undo / Redo с глубиной до 100 шагов.
* **Контекстное меню** по правой кнопке: добавление объектов и фактов, переключение mandatory / uniqueness / preferred, выбор и редактирование элементов, экспорт.

### Ограничения (constraints)

Мастер ограничений работает от текущего выделения ролей и поддерживает два режима — упрощённый и расширенный. Доступные типы:

| Тип | Назначение |
| --- | --- |
| Внутренняя уникальность | Internal uniqueness по выбранным ролям |
| Предпочтительная уникальность | Preferred identifier |
| Внешняя уникальность | External uniqueness |
| Mandatory (IOR) | Дизъюнктивная обязательность |
| XOR | Исключающее ИЛИ |
| Subset | Подмножество |
| Equality | Равенство |
| Exclusion | Исключение |
| External frequency | Частотное ограничение с диапазоном `min`/`max` |

Дополнительно:

* переключение **mandatory** для отдельной роли и **uniqueness** для набора ролей;
* флаг **preferred** и выбор цели `PreferredFor`;
* именование ограничений;
* **фильтр отображения** ограничений на диаграмме и в панелях: Все / Uniqueness / Mandatory / External;
* проверка конфликтов уникальности (`validateUniquenessConflicts`);
* перетаскивание символов ограничений и точек внутренней уникальности.

### Нотация Barker ER

Переключатель **«Нотация»** в заголовке блока «Диаграмма» меняет отображение между ORM и Barker ER.

* **Атрибуты** — поглощение ValueType в атрибуты сущностей (по умолчанию включено). Работает для обеих ориентаций факта `EntityType ↔ ValueType`.
* **Роли** — показ подписей ролей (по умолчанию включено).
* **Barker-style обозначения без вороньих лапок:** optional role — кружок, mandatory role — перпендикулярная черта к линии связи; обозначения рисуются поверх сущностей отдельным overlay-слоем.
* **Подписи ролей с кардинальностью** в квадратных скобках: `включает [1..*]`, `принадлежит [0..1]`.
* Подписи **перетаскиваются мышью** в произвольное место, автоматически разрешается наложение, длинный текст переносится максимум на 2 строки.
* **Панель потерь Barker ER** — что не удалось выразить в нотации при преобразовании из ORM.

Оба переключателя видны только в режиме Barker ER и скрываются при `Нотация = ORM`.

### Бизнес-правила на русском языке

Левая панель принимает текстовые правила, разбирает их и применяет к модели: создаёт объекты, факты и ограничения.

**Распознаваемые шаблоны:**

1. `X определяется через { ... }`
2. `X имеет атрибут Y`
3. `Каждый|Каждая|Каждое|Каждые A P <квантор> B`
4. `A P <квантор> B` — если сущности вокруг квантора определяются
5. `Возможно, что некоторый A не P ни одного B`
6. `Возможно, что некоторый A P более одного B`
7. `Возможно, один A относится к одной или более сущностям B`
8. Preferred composite identification (развёрнутый шаблон)
9. Тернарный факт: `A P B и C`
10. Бинарный факт: `A P B`
11. Унарный факт: `A свойство`

**Кванторы:** `только один/одна/одно`, `ровно один/одна/одно`, `один/одна/одно`, `один или несколько`, `один или более`, `по меньшей мере один`, `не более одного/одной`, `ноль или один`, `ноль или несколько`, `ноль или более`.

Также в панели: диагностика по текущей строке, предпросмотр разбора, подсветка распознанного фрагмента, сохранение правил в TXT.

### Вербализация диаграммы

Автоматическая вербализация модели на русском языке с обратной связью:

* клик по пункту списка **выбирает** соответствующий элемент диаграммы;
* выполняется **автоцентрирование** на элементе;
* элемент получает **отдельную яркую подсветку** (розово-малиновый акцент) поверх диаграммы.

### Навигация и просмотр

* **Масштаб** от 25 % до 400 % через список или колесо мыши.
* **Режимы курсора:** выбор и «рука» (панорамирование).
* **Рамочное выделение** (marquee) и множественный выбор элементов.
* **Поиск** по именам объектов, фактов и чтений с подсветкой совпадений и приглушением остального.
* **Складывающиеся боковые панели** с регулируемой шириной: левая — бизнес-правила и вербализация, правая — свойства и ограничения.

### Экспорт и отчёты

* **Экспорт диаграммы** в SVG и PNG (объединённый dropdown).
* **Панель XML/отчётов:** XML для сохранения, исходный загруженный XML, текстовый отчёт проверки модели.
* **Отчёт совместимости с NORMA** — скачивается отдельным файлом.
* **Сохранение бизнес-правил** в TXT.

## Технические детали

* Отрисовка диаграмм — нативный SVG, без графических библиотек.
